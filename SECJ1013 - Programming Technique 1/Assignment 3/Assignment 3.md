# Assignment 3

### Assignment Instruction
This assignment must be done in pairs consisting of 2 members. There are two sets of questions and we need to follow the set number as our previous assignment. The program must follow the required input and output formats as stated in the questions and examples. All programs must be tested using the sample inputs provided.

### Content of Set 1
* Read team ID, participant ID, and scores for five events from an input file into an array
* Handle file input errors and notify the user if the file fails to open
* Calculate the total score for each participant
* Calculate the total score for each team
* Determine the individual winner and group winner using user-defined functions
* Output all results neatly into an output file
